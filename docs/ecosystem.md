## Studio Principles

1. **Local & Autonomous First**: Giving users direct ownership over intelligent tools without mandatory cloud subscription lock-in.
2. **Specialized Agents Over Monoliths**: Assigning distinct roles (architecture, database, testing, UI) rather than relying on one generic model prompt.
3. **Continuous Shipping**: Building in public, delivering real binaries and deployed web applications that solve specific user challenges.
