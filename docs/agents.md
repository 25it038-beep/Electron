# Specialized AI Agents

Electorn AI organizes development into specialized engineering roles, mirroring a high-performing software company.

---

## Agent Directory

| Agent | Icon | Role | Key Responsibilities |
| :--- | :---: | :--- | :--- |
| **Architect** | 🧠 | Lead System Architect & PM | Requirements analysis, tech stack selection, architecture blueprint, file manifest planning. |
| **Database Engineer** | 🗄️ | Data Modeling & Storage Specialist | SQL/SQLite schemas, SQLAlchemy/ORM models, migrations, indexing, and seed data. |
| **Backend Developer** | ⚙️ | Server & Business Logic Specialist | REST/API endpoints, service layer, core algorithms, security validations, error handling. |
| **UI/UX Designer** | 🎨 | Design System & Styling Specialist | Design tokens, color palettes, responsive layouts, CSS variables, typography. |
| **Frontend Developer** | 💻 | Client Interface & UX Specialist | Interactive UI components, HTML templates, client-side JS logic, responsive forms. |
| **Integration Specialist** | 🔌 | API & Systems Glue Engineer | Configuration loaders (.env), API clients, CORS setup, subsystems interconnection. |
| **QA Engineer** | 🧪 | Test Automation & Quality Specialist | Comprehensive unit, functional, and integration test suites (`pytest`), edge case coverage. |
| **DevOps Engineer** | 🚀 | Environment & Setup Specialist | `requirements.txt`, `pyproject.toml`, Dockerfile, environment setup, and `README.md`. |

---

## Agent Collaboration Pipeline

1. **Phase 1: Architecture & Planning**: The **Architect** turns the prompt into a structured `ProjectSpecification`.
2. **Phase 2: Data Foundations**: The **Database Engineer** models entities and persistence contracts.
3. **Phase 3: Core Logic**: The **Backend Developer** implements business logic and API endpoints.
4. **Phase 4: User Experience**: The **Frontend Developer** and **UI/UX Designer** construct interfaces.
5. **Phase 5: Subsystem Glue**: The **Integration Specialist** connects frontend, backend, and environment configs.
6. **Phase 6: Quality Assurance**: The **QA Engineer** writes automated unit and integration tests.
7. **Phase 7: DevOps & Packaging**: The **DevOps Engineer** produces dependency manifests, execution scripts, and documentation.
8. **Phase 8: Verification & Self-Repair**: The **SyntaxChecker** and **TestRunner** execute validation. If errors arise, the **SelfRepairEngine** activates relevant agents to repair the code in real-time.
